# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-29

### Added
- Initial release
- Multi-registry publishing support
- NPM registry publisher
- GitHub Packages publisher
- Gitea Packages publisher
- Supabase Storage publisher
- PocketBase Storage publisher
- {{VAR}} environment variable replacement
- CLI commands: publish, init, verify, list
- Smart defaults for configuration
- Dry run mode
- Target specific registries
- CI/CD integration examples
- Comprehensive documentation

### Features
- Non-interactive mode for CI/CD
- Automatic cleanup of temporary files
- Secure token handling
- Exit codes for automation
- Build command auto-detection
- Custom NPM arguments support
