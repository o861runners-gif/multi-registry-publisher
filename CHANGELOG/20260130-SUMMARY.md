# Tóm tắt các thay đổi

## 🎯 Giải quyết vấn đề

**Vấn đề ban đầu:**
- 1 source code nhưng cần publish lên nhiều host
- Mỗi host yêu cầu package name khác nhau (do scope khác nhau)
- Dùng chung 1 file tgz gây xung đột
- Version không tự động tăng

**Giải pháp:**
✅ Tạo package.json riêng cho từng registry với scope phù hợp
✅ Pack thành file .tgz riêng biệt cho từng registry
✅ Tự động generate version: `1.yy.mmdd.1hhMM`
✅ Cập nhật NPX.md với lệnh chạy trực tiếp

## 📝 Files thay đổi

### 1. `src/core/publisher.js` - CÁC THAY ĐỔI CHÍNH

#### Thêm 3 methods mới:

**a) `generateVersion()`** - Tạo version tự động
```javascript
generateVersion() {
  // VD: 30/01/2026 15:45 → "1.26.0130.11545"
  const now = new Date();
  const yy = String(now.getFullYear()).slice(-2);
  const mm = String(now.getMonth() + 1).padStart(2, '0');
  const dd = String(now.getDate()).padStart(2, '0');
  const hh = String(now.getHours()).padStart(2, '0');
  const MM = String(now.getMinutes()).padStart(2, '0');
  return `1.${yy}.${mm}${dd}.1${hh}${MM}`;
}
```

**b) `createRegistryPackage(registry, originalPkg)`** - Tạo package.json riêng
```javascript
// Input: originalPkg = { name: "my-package", version: "1.0.0" }
// Output cho npmjs:     { name: "my-package", version: "1.26.0130.11545" }
// Output cho codeberg:  { name: "@o861runners/my-package", version: "1.26.0130.11545" }
// Output cho github:    { name: "@myusername/my-package", version: "1.26.0130.11545" }
```

**c) `packForRegistry(registry, pkgPath)`** - Pack riêng cho từng registry
```javascript
// Flow:
// 1. Backup package.json gốc
// 2. Thay thế bằng package.json của registry
// 3. npm pack
// 4. Đổi tên: registry-name-package-version.tgz
// 5. Restore package.json gốc
```

#### Sửa method `run()`:
```javascript
// Old: Pack 1 lần rồi dùng chung
// New: Pack riêng cho từng registry

for (const registry of this.registries) {
  // 1. Create registry-specific package.json
  const { pkgPath, pkg } = await this.createRegistryPackage(registry, originalPkg);
  
  // 2. Pack với package.json đó
  const artifactPath = await this.packForRegistry(registry, pkgPath);
  
  // 3. Publish file .tgz riêng
  await registry.publish(artifactPath);
}
```

### 2. `NPX.md` - FILE MỚI

Hướng dẫn chi tiết cách chạy package trực tiếp từ các registry:

**Sections:**
- NPM Registry commands
- GitHub Packages commands
- Gitea/Codeberg commands
- Troubleshooting
- Tips & Tricks
- Quick Reference Table

**Ví dụ lệnh:**
```bash
# NPM
npx --yes @scope/package args

# Codeberg
npx --yes --registry=https://codeberg.org/api/packages/owner/npm/ @owner/package args

# GitHub
npx --yes --registry=https://npm.pkg.github.com @user/package args
```

## 🚀 How to Use

1. **Cấu hình registry với scope:**
```json
{
  "registries": {
    "npmjs": {
      "type": "npm",
      "enabled": true
    },
    "codeberg": {
      "type": "gitea",
      "url": "https://codeberg.org",
      "owner": "o861runners",
      "enabled": true
    }
  }
}
```

2. **Publish:**
```bash
npm-multi-publish publish
```

3. **Test:**
```bash
npx --yes my-package hello
npx --yes --registry=https://codeberg.org/api/packages/o861runners/npm/ @o861runners/my-package hello
```
